Research Publications Experience

Amit Choudhari

PhD Student · CISPA Helmholtz Center for Information Security

I am a PhD student at CISPA in the System Security group, advised by Prof. Christian Rossow. I work on microarchitectural and systems security, with recent work on secure in-memory computing, malicious SmartNICs, and undocumented CPU prefetchers.

Before starting my PhD, I spent several years at Qualcomm working on ARM TrustZone- and hypervisor-based security. I particularly enjoy reverse-engineering undocumented CPU behavior, especially hardware prefetchers.

Open to research and R&D roles beginning in 2027 in systems, microarchitecture, and hardware security.

Microarchitectural security

Systems security

Linux kernel security, trusted execution, hypervisors, and hardware–software isolation.

Network & accelerator security

SmartNICs, processing-in-memory systems, embedded platforms, and their interaction with host software.

Publications & patent

2026USENIX Security

Memclave: Secure In-Memory Enclave for Untrusted Hosts

Amit Choudhari, Fabian van Rissenbeck, Christian Rossow

Protects code and data on commodity UPMEM PIM using a TPM-attested hypervisor and an in-PIM trusted loader.

2025ESORICS

NICraft: Malicious NIC Firmware-Based Cache Side-Channel Attack

Amit Choudhari, Shorya Kumar, Christian Rossow

Shows how malicious NIC firmware can use Linux IP reassembly to mount host cache side channels, including keystroke-activity detection at 96% precision.

2023ACM CCS

FetchBench: Systematic Identification and Characterization of Proprietary Prefetchers

Till Schlüter, Amit Choudhari, Lorenz Hetterich, Leon Trampert, Hamed Nemati, Ahmad Ibrahim, Michael Schwarz, Christian Rossow, Nils Ole Tippenhauer

Characterizes undocumented prefetchers across 19 ARM and x86-64 CPUs and uncovers a replay-based prefetcher on Cortex-A72.

2022ASHES @ CCS

SpecDefender: Transient Execution Attack Defender Using Performance Counters

Amit Choudhari, Sylvain Guilley, Khaled Karray

Detects Spectre activity with hardware performance counters and restarts the application with Spectre defenses when an attack is detected.

2021NICS

CRYScanner: Finding Cryptographic Libraries Misuse

Amit Choudhari, Sylvain Guilley, Khaled Karray

Detects cryptographic-library misuse, including unsafe API call sequences and parameters.
