Publications

2026USENIX Security

Memclave: Secure In-Memory Enclave for Untrusted Hosts

Amit Choudhari, Fabian van Rissenbeck, Christian Rossow

A software-only framework that adds code integrity and data confidentiality to commodity UPMEM PIM using a TPM-attested hypervisor and an in-PIM trusted loader.

2025ESORICS

NICraft: Malicious NIC Firmware-Based Cache Side-Channel Attack

Amit Choudhari, Shorya Kumar, Christian Rossow

Uses Linux IP reassembly to let malicious NIC firmware mount cache side channels on commodity systems, including keystroke-activity detection at over 96% precision.

2023ACM CCS

FetchBench: Systematic Identification and Characterization of Proprietary Prefetchers

Till Schlüter, Amit Choudhari, Lorenz Hetterich, Leon Trampert, Hamed Nemati, Ahmad Ibrahim, Michael Schwarz, Christian Rossow, Nils Ole Tippenhauer

A cross-platform framework for identifying and characterizing undocumented hardware prefetchers; evaluated on 19 ARM and x86-64 CPUs and used to uncover a replay-based prefetcher on Cortex-A72.

2022ASHES @ CCS

SpecDefender: Transient Execution Attack Defender Using Performance Counters

Amit Choudhari, Sylvain Guilley, Khaled Karray

Dynamically detects Spectre activity using hardware performance counters and restarts the application with Spectre defenses when an attack is detected.

2021NICS

CRYScanner: Finding Cryptographic Libraries Misuse

Amit Choudhari, Sylvain Guilley, Khaled Karray

A generic analysis tool for detecting cryptographic-library misuse, including unsafe call sequences and parameters.
